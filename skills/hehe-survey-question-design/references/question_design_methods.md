# 题目设计方法

用于把研究材料加工成可回答、可比较、能支持决策的问卷。按本次需要阅读相关部分；设计依据记入现有底稿，问卷正文保留受访者需要的信息。

## 一、从材料形成变量与选项

1. **按研究问题读材料。** 从 brief、历史问卷、访谈、用户反馈和产品资料中提取“谁—什么场景—做什么—现有办法—结果或问题”。先覆盖已经确认的研究问题，再补新发现。
2. **定向补缺口。** 陌生品类、场景或选项依据不足时，用“对象＋任务／使用问题／替代方案”等词搜索，打开原文；产品资料查功能与使用条件，公开研究查概念与分类，用户原话查实际表达和遗漏的选项。使用当前可用的搜索、浏览器或数据库即可。
3. **加工候选选项。** 把专业词改成受访者的表达，合并同义项，保留会导向不同产品行动的差别。例如“清洁不便”可按研究需要拆成“缝隙刷不到”“拆装费时”“污物容易沾手”；这些是设计示例，实际采用依据本题材料。
4. **保留探索空间。** 已知分类形成封闭选项，未覆盖内容可用“其他，请说明”或少量开放题补充。核心问题缺材料时可自拟候选题，在底稿记录待验证点，继续形成完整初稿。

在变量表“测量原因”中简记材料位置、支持的选项及加工理由，区分原文发现和设计假设。帖子出现次数用于寻找线索，不作为总体人群占比。若材料提供的是供给方卖点，先转为用户可识别的体验或任务，再决定是否入题。

开放题同时说明如何使用答案：准备初始编码类别，预留新增类别，规定一条回答可单码还是多码；根据答案完善类别后再计数。需要测自发认知或未提示的原因时，把开放题放在相应提示列表之前。

## 二、确定测量口径与回答尺度

### 把问题问到受访者能回答的程度

| 要确定的内容 | 设计动作 |
|---|---|
| 对象与单位 | 明确回答自己、家庭、某只宠物、一个账号或一家企业；单次购买、月支出、使用天数等单位写入题干 |
| 时间与回忆 | 高频行为可问近期天数或次数，低频购买可问最近一次或较长时期；同一比较采用相同时间窗，具体期限按事件频率与项目目标选择 |
| 多对象家庭或多产品使用者 | 明确逐个回答还是选定一个对象贯穿后续。选定规则放在前面，相关题持续指向该对象 |
| 知情程度 | 采购者回答采购决策，使用者回答体验；不知情者分流或允许“不知道”，避免要求其代猜金额、组织决策等 |
| 状态与缺失 | 区分实际为零、没有经历、无法评价、记不清和跳题未答；字段字典保留区别 |

例：“您经常使用 AI 吗？”可根据目标改为“过去7天，您有几天使用AI工具处理工作任务？”；要测调用次数时另定义一次使用的含义，不能把天数与次数混算。

### 用合适的答案测量变量

- **行为事实**：选择次数、天数、金额或明确区间；区间边界互斥且覆盖零值与高端。精确回忆困难时使用有业务意义的区间，或允许估计并说明。
- **评价与意愿**：直接询问满意程度、重要程度或发生意愿，选项覆盖相应方向并说明各档含义。中间态度与“不适用／无法评价”分别编码；有序选项固定排列。
- **实际体验与新概念**：体验评价只问有相应经历者。新功能先给各人相同的中性描述、条件和价格信息（若涉及），再问预期价值或选择意愿。
- **复杂构念**：先定义所含侧面，再选取各有作用的题项。采用或改编既有量表时核对原文、适用人群、题项、响应尺度及计分方法，在底稿注明来源与改动；自编题通过预试检查含义和覆盖。题数由测量内容决定，普通行为题保持直接问法。
- **可比性**：跨品牌、人群或前后时期比较时，核对对象、时间、题干、尺度和提问方式；只能评价熟悉对象的人进入对应比较。新增题型或改尺度后，说明旧数据还能如何比较。

## 三、从拟做的分析倒推答案与样本

在现有“题目用途与分析映射表”中把“做交叉分析”具体写成“用哪些答案、比较谁、分母是什么、支持哪项判断”。

| 研究判断 | 所需题目或已有信息 | 设计时核对 |
|---|---|---|
| 哪类人需求更强 | 人群分类、相同口径的需求或行为题 | 每组都有机会回答目标题；分流后实际可用人数 |
| 哪类痛点值得改善 | 是否经历、必要的频率或影响、当前解决办法 | 按决策选择所需追问；区分全体中的发生率与经历者中的严重程度 |
| 品牌为什么被选择、持续使用或替换 | 过去与当前状态、具体场景、对应原因与体验 | 选择、持续和切换分别对应真正经历该过程的人；同一场景的品牌与原因可关联 |
| 满意度为何不同 | 总体与相关方面的评价、需比较的使用条件 | 同一人评价多个品牌时保留配对关系；单次观察问卷用于差异和关联解释 |
| 哪些因素影响购买 | 实际购买或未购买状态、候选因素、相关使用条件 | 因素多选得到提及率，排序得到相对次序；需要估计取舍或检验因果时选相应设计 |

只有项目需要样本规划或关键分组明显难以招募时，进一步确定目标精度或最小关注差异、分组方式和预计进入比例。先估每条关键路径能留下多少人，再决定招募、配额或拆卷安排。

需要数值计算时，核对所用方法及假设：比例精度与组间差异检验使用不同的计算；区分配对和独立分组，并考虑设计效应、无效回答和路径损耗。未知进入比例用有依据的情景估算。预算固定时据此说明可支持的比较粒度；自愿参与或配额样本的计算精度不代表总体代表性。将假设和结果写在既有样本决策栏，不另设统一的每组最低人数。

## 四、产品、概念与竞品测试的比较设计

按研究目标确定以下安排，写入详稿的问卷说明及实际呈现位置：

- **比较方式**：每人只测一款时，明确组别分配及组间可比条件；同人测多款时，保留配对评价。按目标选择，已有使用经验与现场体验分别记录。
- **品牌与价格**：测产品本身的体验时，决定是否隐藏品牌、先完成不含报价的评价；测购买选择时提供相应品牌、售价与服务条件。明确每项信息何时展示，区分展示前后的评价。
- **体验与提问顺序**：同人测多款时安排产品顺序轮换，并处理学习、疲劳或前款体验的残留影响；难以消除时改用独立分组。需要分别评价各款时，先完成单款评价，再问总体偏好；任务及评价口径保持可比。

组别、产品／概念版本、实际呈现顺序和受访者编号记入现有底稿与字段；同人多次评价保留关联，不按评价条数增加独立样本数。
