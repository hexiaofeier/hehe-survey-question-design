# 问卷交付物格式

## 输出总结构

完整设计任务默认交付**三份文件**：同版《问卷建卷详稿》的 Markdown（`.md`）和 Word（`.docx`），供内部人员和用户确认修改；另交一份 Markdown《问卷导入稿》，供问卷星等平台文本导入。其他平台按用户指定适配。局部改题或问卷质检只交付受影响内容。

## 问卷导入稿（Markdown）

导入稿只保存为 UTF-8 `.md`，全文可复制到问卷星文本导入入口。题干与每个选项各占一行，题间留空行，题号使用普通文字；标题、说明和结束语仅采用平台已支持的导入写法。按作答顺序保留全部题目、完整题干和逐条选项，不混入建卷说明、分区标题、字段表、质检结论或逐题配置。

题型、选答例外、限选、随机/固定、互斥、显示/终止条件、引用取值及开放题长度写入两份同版建卷详稿；Base、字段名、研究依据、变量和质检留在设计底稿。详稿中的内部选项代码对应导入稿原始顺序，不出现在受访者可见的选项中。

受访者需要的调查介绍、作答对象和概念／方案说明属于实际问卷内容，按平台支持的说明或题干格式保留；不支持文本导入时，在详稿原位置用 `[受访者说明，建卷时补入]` 标明。导入后核对实际展示，内部研究目的、配额表和编码说明仍只给建卷人员。

问卷星默认文本样式：题干以连续数字题号开头，题干和每个选项各占一行，题间空一行；单选题不加题型标签，多选题在题干后标 `[多选题]`，单项填空题以冒号结尾。选项文字不加字母或数字前缀；半角空格会被解析器用于分隔选项，选项内应去除多余空格或改用保留原意且不拆项的写法。量表、矩阵、排序等题型按平台支持的格式生成，并保留原测量设计。可操作平台时实际检查导入或预览：题型、题干、完整选项及其数量、其他填空归属均应与设计一致；不能识别的题型单列设置方式。格式可参考问卷星公开的[文本创建问卷示例](https://www.wjx.cn/help/help.aspx?helpid=138&h=1)。

## 问卷建卷详稿（Markdown 与 Word）

两份详稿的标题、版本、问卷说明、分区、题号、题干、标签及选项逐段一致。开头设简短“问卷说明”，说明设计目的和判断用途、调查对象与研究口径、问卷结构、主要甄别与分流逻辑、配额已确认值或待确认状态，以及代码与默认规则；未确认的数值不代填。甄别、终止和动态选项在相关题目写明，不另造一套逐题配置表。

上述“问卷说明”用于内部审阅；给受访者的介绍与模块提示另在实际出现的位置写出，不能用内部说明代替。

建卷稿在题目之间用简短的“一、甄别部分”“二、用品使用与采购行为”等标题分区；按研究问题设置分区，覆盖整份问卷，不把分区说明写成逐题长段。各区内保持纯导入稿的题号和顺序。纯导入稿仍按平台文本格式，不插入不能识别的分区标题。

每题只用一行“题号、题干＋方括号标签”，下方逐行列选项。题型必写，有选项的题写呈现方式，纯填空题不写“选项固定/随机”；限选、选答、整题或单项显示、跳转、互斥、引用来源、字数限制只在适用题写。`c01` 起按本题选项原始顺序编号，供标签引用，不加在选项文字前。默认必答、所有合格受访者回答、选项均显示、顺序进入下一题；这些默认项不逐题重写。分流题标明选中代码后的去向；随机题标明随机范围和固定置底项；动态选项标明来源题及保留顺序。题干不与选项混配。例如：

```text
4、关于家中猫或狗的日常照顾和用品选购，哪项最符合你的情况？[单选题][选项固定][仅第3题∈c01—c03时显示][选c04→终止；c01—c03→第5题]
我主要负责选购用品，也了解日常照顾情况
我和家人共同选购用品，也了解日常照顾情况
我了解日常照顾情况，但用品通常由家人选购
我既不了解日常照顾情况，也不参与用品选购
```

特殊题型继续使用简短标签，矩阵仅增加“行项目”“列选项”两组内容；以下为详稿示例，不是平台导入语法：

```text
8、您对最近一次购买的宠物用品，以下方面分别有多满意？[矩阵单选题][行项目随机][列选项固定][每行单选]
行项目：
耐用程度
清洁便利性
列选项：
非常不满意
比较不满意
一般
比较满意
非常满意
未体验或无法评价

9、选购宠物用品时，您最看重哪些因素？请选出并排列前三项。[排序题][选项随机][选3项排序][第1位最重要][不可并列]
价格
质量
清洁便利性
外观

10、过去30天，您家购买猫狗用品共花费多少元？不含食品和医疗费用。[数字填空题][单位：元][允许0及正数][最多2位小数]

11、您最希望改善哪一项宠物用品使用问题？[填空题][选答][最多200字]
```

矩阵引用行项目用 `r01` 起编号，列选项用 `c01` 起编号，仅供标签引用。动态引用保留来源题原代码与文字对应关系，筛选或随机展示后不按屏幕位置重编号；仅无可用选项时跳过该题，有常驻选项或需终止时在标签写明处理。多选涉及多个后续模块时，用各模块显示条件依次展开；确需互斥跳转时，写清同时命中的优先级或合并去向。跳转目标的显示条件也须满足，否则标明下一可答题或结束。

Word 详稿按 Markdown 详稿生成，保留问卷说明、分区标题、逐题标签和全部选项，供阅读、批注和修改；不另写一套文字。字段、Base、研究假设、变量映射与质检留在设计底稿，按需提供。交付前核对两份详稿逐段一致，再核对三份文件的题号、题干、选项和顺序，并走查非默认规则。
