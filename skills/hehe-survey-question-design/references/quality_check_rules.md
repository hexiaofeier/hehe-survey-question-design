# 问卷质检规则 v0.1

## 质检目标

问卷质检不是润色题干，而是检查：

`研究目标 → 变量 → 题目 → 数据字段 → 样本/执行作用或分析结论`

是否形成闭环。

## 必检清单

| 检查项 | 问题信号 | 处理方式 |
|---|---|---|
| 目标闭环 | 某个研究目标没有题目支撑 | 补题或调整设计；放弃已确认目标须由用户确认 |
| 必答问题漏测 | brief 或报告大纲中的具体问题没有对应题目，或分流后缺可分析 Base；总体题被用来代替场景、品牌或人群问题 | 补题、调整分卷与样本；放弃该问题须由用户确认 |
| 孤儿题 | 题目既不服务甄别、配额、跳题或质检，也不支持分析或决策 | 建议删除或请用户判断 |
| 样本 Base | 主体题没有明确回答对象 | 补充跳题和 Base |
| 变量缺失 | 只有题目，没有变量定义 | 退回变量表补充 |
| 内容依据不足 | 陌生品类仍只有通用选项，或直接照搬供给方卖点 | 回到材料提炼具体场景、体验和替代方案；自拟选项留待预试 |
| 测量口径混淆 | 对象、时间、单位不明；回答者不知情；零值、未经历和无法评价混用 | 明确口径，调整回答对象或选项编码；比较题保持可比 |
| 分析无法落地 | 只写分析方法名，缺所需答案、交叉字段或分流后人数安排 | 补齐具体题目与分析映射，按项目需要调整样本或分卷 |
| 题目与底稿脱节 | 详稿题号找不到变量、字段或Base；底稿与详稿保留了相互冲突的题目版本 | 完整题目和配置以同版详稿为准；底稿按题号关联变量、字段、Base和分析用途；导入稿同步题目内容 |
| 交付或建卷规则不可执行 | Markdown与Word详稿内容不一致；纯导入稿夹杂配置；选项内半角空格造成拆项；详稿缺问卷说明、分区、题干、选项、配额状态及必要的显示、跳转、随机规则；引用代码与导入稿选项不一致 | 交付Markdown建卷详稿、同内容Word阅读详稿及Markdown纯导入稿；先核对两份详稿的标题、说明、分区及逐题内容，允许Word段落和表格布局不同，再核对三份文件的题号、题干、选项和原始顺序；按文本格式核对题型、选项数量、其他填空归属并静态走查路径 |
| 行为缺失 | 研究目标需要行为解释，但题目只有态度 | 补充对应的使用阶段、频率、场景或购买题 |
| 原因或评价缺失 | 研究目标要求解释原因或评价，但只取得行为事实 | 补充所需的动因、痛点、满意度或意愿题；只调查行为事实时不强加 |
| 分层缺失 | 研究要求比较的人群无法区分 | 补充所需的人群分类或派生规则；已有分层信息可沿用 |
| 选项边界或排他关系错误 | 单选类别重叠；多选把可共存角色误设互斥，或“以上均无”可与实质选项同选 | 单选明确分类边界；多选保留合理共存、合并同义项并注明排他项 |
| 选项不穷尽 | 受访者可能无选项可选 | 增加“其他”“不确定”“不适用”等 |
| 选项顺序错误 | 有序变量被随机，随机变量被固定 | 修正为固定/随机/逻辑顺序 |
| 选项随机性缺失 | 有选项的题未标注固定或随机 | 补充呈现规则；纯填空题底稿记“不适用”，详稿不加标签 |
| 双重问题 | 一道题同时问两个判断 | 拆题 |
| 诱导表达 | 题干暗示正确答案或过度正向 | 改为中性表达 |
| 问卷负担 | 只报总题数，未核对各人群实际路径；矩阵、开放题、长列表或说明阅读负担过重 | 在样本决策栏记录路径题量、矩阵回答项目、阅读负担及估计／实测用时；按目标调整、复核覆盖 |
| Kano 错配 | 已选用 Kano，却只问功能喜欢，不问不能实现 | 补成正反成对题；普通功能评价不自动改为 Kano |
| 品牌链路断裂 | 要研究品牌使用、迁移或忠诚，却只取得认知数据 | 补齐目标所需环节；认知专项不强制补完整链路 |

## 重点检查规则

### 1. 研究目标检查

每个研究目标必须至少对应：

- 一个研究问题；
- 一个变量；
- 一道或一组题；
- 一个样本/执行作用，或一个后续分析与报告用途。

如果任一环节缺失，标记为 `目标链路不完整`。

再按 brief 和报告大纲逐项核对必答问题：每项都应能指出题号和可分析的 Base。缩短、合并或分卷问卷后重新核对；题目虽存在但对应人群答不到、样本不足以分析，或只得到总体答案而无法回答指定场景的问题，均列为必须修改。

### 2. 题目价值检查

每道题都必须回答：

- 为什么问；
- 测什么变量，或控制什么样本/执行条件；
- 谁来回答；
- 后续怎么使用；主体分析题还需说明分析方式和能支撑什么结论。

无法回答的题标记为 `孤儿题候选`。

### 3. 选项检查

选项需检查：

- 单选分类边界是否清楚，多选共存与排他关系是否正确；
- 是否穷尽；
- 是否需要“其他”；
- 是否需要“不知道/不适用”；
- 是否有逻辑顺序；
- 是否应随机；
- 是否存在过长、过细、难理解表达。

“其他”“以上均无”“不知道”“不适用”是否置底，应明确写入规则。

有选项的题显式标注选项随机性；非随机题也写“选项固定”，纯填空题不加此标签。如包含“其他”“以上都没有”“说不清”“不适用”等排他或兜底选项，需写明是否固定置底。矩阵核对行项目、列选项及各自顺序；排序核对排序数量与并列规则；数字填空核对单位和允许范围，格式按 `output_schema.md`。

### 4. 跳题和 Base 检查

每道非全员题必须写明：

- 显示条件；
- 来源题；
- 回答对象；
- Base；
- 终止或跳转规则。

隐藏题和派生变量也必须写明规则。

详稿用与题干相邻的简短标签区分整题显示与单项显示；动态引用写来源题、选项代码和顺序，随机题写随机范围与置底项。默认必答、全员显示和顺序下一题无需逐题重复。配额写明数值与控制题；未设或待确认时明示状态，不编造数值。

按样本决策记录走查配额：独立限制与交叉单元是否一致，占位、完成、退出及满额路径是否可执行；受访者说明与概念材料是否已写在对应题目之前，并有明确呈现规则。

走查多选同时命中分支、动态引用无可用选项及跳转后目标题不显示的路径。多模块按显示条件依次作答；互斥去向有明确优先级或合并去向。每条路径能继续或明确结束，引用代码能对应原始选项。

### 5. 量表检查

量表题需检查：

- 分值方向是否一致；
- 是否写明高分含义；
- 是否使用 5 分、7 分、10 分或 NPS；
- 是否能计算 TOP2、均值或 NPS；
- 是否适合矩阵呈现。

同一问卷内同类量表尽量保持一致。

核对量尺起止值、各档含义和实际测量内容；中间态度与“不适用／无法评价”分开，后者不作为中间分计入均值。采用或改编既有量表时核对底稿中的原文、适用对象及改动；具体方法见 `question_design_methods.md`。

选用专项题组时按 `specialized_question_modules.md` 检查其完整输入：Kano正反配对与类别编码、NPS原始0—10分、价格口径与分组、MaxDiff或联合分析的任务设计及呈现记录。

### 6. 场景题检查

场景题必须具体到任务。不要只写：

- 工作；
- 学习；
- 生活；
- 娱乐。

应拆成可回答、可行动的任务，如：

- 搜索问答；
- 文本写作；
- 视觉创作；
- 工作办公；
- 学习备考；
- 孩子学习辅导；
- 采购决策；
- 售后服务。

### 7. 品牌题检查

按研究目标从以下品牌环节中选用并检查对应题目；只有研究完整迁移或忠诚链路时才展开相关时间轴：

- 知道；
- 用过；
- 当前仍在用；
- 最常用或核心；
- 曾经常用但流失；
- 从其他品牌迁移而来；
- 一直使用；
- 未来可能转向。

不能只用“知道哪些品牌”替代竞争分析。

### 8. 预试与修订

用户另行要求预试时，按关键人群与分支选择目标受访者，先独立答题，再追问关键题或犹豫处：

- 请其用自己的话复述题意，确认理解的对象与时间；
- 请其说明回忆了哪次经历、怎样得到答案，识别难以回忆或不知情的问题；
- 请其解释为何选择该项、是否有缺少或重叠的选项，区分真实中立与无法回答；
- 对矩阵、排序和长题观察手机阅读、作答负担与用时。

文件静态走查覆盖甄别、配额、显示、跳转、随机呈现及字段对应。根据发现修改题干、选项、时间窗或分支，再复查受影响路径。实际预试的人数与轮次按问题和人群覆盖决定；分别记录已执行的读者预试或静态走查及其结果。

## 质检输出格式

| 等级 | 含义 | 输出要求 |
|---|---|---|
| 必须修改 | 会影响样本、变量、统计或结论 | 明确给出修改方案 |
| 建议修改 | 不一定致命，但会降低数据解释力 | 给出优化方向 |
| 可保留但备注 | 有风险，但项目上可能需要 | 写明风险和使用边界 |
| 待用户确认 | 需要业务判断或公司要求 | 列出选项与影响 |

## 禁止事项

- 不得用背景信息替代用户洞察。
- 不得让 AI 自行补齐高风险样本配额。
- 不得把方向性差异预设成结论。
- 不得忽略小样本、跳题和 Base 差异。
